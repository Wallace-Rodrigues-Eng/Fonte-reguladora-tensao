# Fonte Regulada de Tensão

### Objetivo
Desenvolver uma fonte regulada de tensão para fins acadêmicos, abordando desde os cálculos elétricos até a simulação do circuito.

### Descrição do Projeto
O projeto consiste no desenvolvimento de uma fonte regulada de tensão, contemplando as etapas de dimensionamento dos componentes, simulação do circuito e documentação técnica. Foram realizados cálculos para retificação, filtragem e regulação da tensão de saída.

### Ferramentas Utilizadas
- Proteus (simulação do circuito)
- EasyEDA (desenvolvimento do esquema elétrico)
- Relatório técnico em PDF

### Conteúdo do Repositório
- Arquivos de simulação no Proteus  
- Projeto do circuito no EasyEDA  
- Relatório técnico com cálculos elétricos  

### Observações
Projeto desenvolvido no contexto acadêmico, com foco no aprendizado de eletrônica analógica e fontes de alimentação.
